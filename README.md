# Digital Resume

CV en ligne en une page, réalisé en HTML et CSS lors de la première semaine du module web d'Epitech (B-WEB-100, 2025).

## Contenu

- Coordonnées et langues
- Parcours scolaire
- Compétences avec niveau représenté visuellement (langages et outils)
- Centres d'intérêt illustrés
- Formulaire de contact

## Stack technique

HTML et CSS, sans JavaScript ni framework.

## Lancer le projet

Ouvrir `index.html` dans un navigateur.
